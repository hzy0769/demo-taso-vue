## 1. 框架（平台基础能力）

### 1.1 多语言与本地化
- 十语言全量目录（每语言 1019 key）：繁中HK / 简中 / EN / 日 / 韩 + 法 / 越 / 泰 / 阿 / 俄（V2.8）
- 偏好模型：界面语言 / 内容地区 / 自动翻译三项独立，显式选择永不被自动重置；账号快照登录合并
- 设备建议冷启动：按设备语言 + 时区给「建议设置」、可跳过；香港不再是全球默认（V2.4）
- 回退链：精确 locale → 语言/文字 → en 基准；缺失 key 警告并回落安全文案
- 复数按各语言 Intl.PluralRules 分支（阿语 6 分支、俄语 4 分支）
- 质量校验三件套脚本：key 奇偶 / 参数占位符 / 逐语言字符混入
- 📋 法律文本按 market+locale+version 精确匹配、TMS 翻译管理流程、伪本地化

### 1.2 时区与格式化
- 金额 Money{amount, currency} + Intl 格式化（US$ / HK$ / JP¥ 无歧义符号）
- 等值换算自带「估算 · 匯率 · 时间」披露；演示汇率表 12 币种
- 时刻存 ISO instant 按用户时区渲染；自然日存 YYYY-MM-DD；相对时间（刚刚 / x 分钟前 / 昨天）

### 1.3 自动翻译（UGC）
- 数据模型 original{text, locale} + translations[]，原文不可变；机器/人工译文标记来源
- 三态呈现：同语言直显原文 / 默认译文 +「显示原文」切换 / 无译文 +「翻译」按钮（绝不误标已翻译）
- 「报告译文问题」反馈入口；评论、私讯默认保持原文（翻译是个人阅读偏好）

### 1.4 内容地区
- 全球 / 国家 / 城市三级 17 城（P503A ScreenContentRegion）：最近使用 + ISO 全清单多语言搜索
- 仅影响推荐排序；与账户国家（KYC）、收货地址严格分离

### 1.5 RTL（阿拉伯语）
- html dir=rtl 随界面语言切换 + CSS 基础镜像
- ⚠️ 完整 RTL 视觉审计（图标语义 / 滑动方向 / 阿拉伯-印度数字）待办

### 1.6 启动与引导
- 启动分流（P001）：已登录恢复上次屏幕 / 回访未登录直达登录页 / 新用户进欢迎页
- 欢迎页（P002）：语言 + 内容语言 + 内容地区，可跳过 → 登录页
- 兴趣选择（P004）：推荐冷启动，可跳过

### 1.7 市场能力矩阵（capability.ts）
- 六能力：会员卡 / 充值 / 提现 / 加密 / 推广 / 分红 × 三态（可用 / 地区未开放 / 需 KYC）
- 所有入口、深链、客服话术统一读矩阵；原型不隐藏入口，只加状态标签；演示 8 市场（HK 全开）

### 1.8 设计系统与工程
- 设计令牌：黑 / 米白 / 品牌金（AA 墨色）；4pt 间距；组件类全走令牌
- 技术：Vite 8 + Vue 3.5 + TS，零额外运行时依赖；栈式路由 + 12 个 localStorage 状态域
- 无障碍：弹层关闭态 inert、焦点进入 / 复位；aria-label 全走 t()
- 📋 深色模式、200% 动态字体、屏幕阅读器深度验收

## 2. 用户中心

### 2.1 注册登录（AUTH PRD v1.0 · V1.3）
- 「继续使用 TASO」统一入口（P003）：Apple / Google / X 品牌按钮 + 邮箱 / 手机号；不区分新老用户
- Email / 手机号输入 + 6 位 OTP：自动跳格、60s 重发倒计时、连错 3 次进异常页（AUTH-003~006）
- OAuth 模拟授权页（AUTH-007，权限清单 + 取消）；新用户昵称 2–30 字符校验（AUTH-008）
- 登录异常统一错误页，不泄露账号注册状态（AUTH-010）
- 📋 AUTH-011 账号锁定页（依赖真实风控）

### 2.2 账号与安全
- 账号与安全总览：TASO ID / 国家 / 语言 / 时区 / 注册时间（AUTH-012）
- 登录方式管理：五种方式绑定 / 解绑；最后一个身份解绑被拦截（AUTH-013/015）
- 设备会话管理：当前 + 其他设备、退出其他设备（AUTH-014）
- 删除账号：删除范围 + 14 天恢复窗口提示 → 二次确认 → 全量重置回首启（AUTH-016/017）
- 登出：撤销 session，账号 / 身份 / 社交 / 余额数据保留

## 3. 会员卡权益

### 3.1 权益首页（P401 · V1.9）
- 三分区优先级：会员卡（卡片 + 余额 + 快捷操作）→ 钱包摘要（可提现 + 待结算）→ 推广与收益

### 3.2 我的会员卡（P401A · 独立卡账户页）
- 卡视觉 + 卡内余额（仅限消费 · 不可提现）+ 充值 / 消费记录
- 申请实体卡 / 配送追踪 / 卡片管理入口
- 卡激活（P401B · V3.2）：未激活态「未激活」徽标 + 全掩码卡号，充值 / 消费记录入口隐藏、仅留「激活会员卡」入口（P401 权益首页同步）；三步 = 填写卡号（实时分组 + 品牌识别 + 前缀/位数校验，演示卡号徽标一键填入）→ 设置卡密码（6 位两遍一致 · 不落任何存储）→ 首次充值（与快捷充值同口径：HK$ 计价 + 16% 手续费 + 汇率换汇 + Quote 披露 + 五支付方式），支付成功即激活
- 激活态：卡面显示所填卡号末四位 + 「已激活」徽标，恢复充值 / 消费记录入口（P401 / P403 联动）；激活态持久化 taso-card，删除账号清除

### 3.3 实体卡全球配送（P402 系列 · V1.8 六步）
- 申请入口（P402）：办理费 HK$1,000/张 + 配送费结算时计算
- 国家选择器（P402B）：22 国中 / 英 / ISO 搜索、推荐置顶、不可配送拦截（冰岛 / 马尔代夫演示）
- 动态地址表单（P402A）：国家配置驱动字段顺序 / 必填 / 校验（HK / JP / US / CN / TW / GB / SG 专属模板 + 通用模板）；区号自动带入；草稿 + 默认地址持久化
- 配送方式（P402C）：Standard 免费（5–10 天）/ Express HK$101.30（2–4 天）；ETA 日期区间动态计算；偏远地区 Express 置灰
- 确认申请（P402D）：汇总可编辑 + 地址确认勾选 + 支付方式选择 + Quote 披露 + Loading
- 申请成功（P402E）：编号 MC-yyyymmdd-xxxxxx 可复制 + 已付费用 + 追踪入口
- 配送追踪（P402F）：五节点时间线 + 承运商运单号（演示停已发货）
- 📋 地址智能补全 / 自动标准化、多地址管理、实时轨迹、关税 VAT

### 3.4 卡片管理（P403）

## 4. 推广中心

### 4.1 推广中心页（P410）
- 数据卡：邀请人数 / 直接邀请 / 总奖励 / 待结算；推广链接复制 + 分享

### 4.2 双轨佣金结构（V2.2 · 比例与层级均为后台演示值）
- 轨道一 购卡佣金：金牌会员 30% / 银牌 5% / 铜牌 1%（= 下级购卡金额 × 层级比例）
- 轨道二 充值佣金：金牌 0.5% / 银牌 0.1% / 铜牌 0.05%（= 下级充值金额 × 层级比例）
- 两轨独立计佣、独立入账（钱包「推广奖励」分类按轨拆分）、互不冲抵

### 4.3 推广详细规则页（P410A）
- 双轨比例表 + 计算示例（金牌层级：下级购卡 HK$1,000 → ≈US$38.46；下级充值 US$10,000 → =US$50）
- 结算规则：入账时点方案与匯率为准 / 购卡退款充值冲正按比例冲回 / 层级以注册邀请关系为准不可变更

### 4.4 命名与合规口径（2026-09-13 定稿）
- 前台统一「金牌 / 银牌 / 铜牌会员」（十语言），禁用一级 / 二级 / 三级、直推等表述；后台仍为 level 1/2/3

- 📋 推荐关系树展示、邀请落地页、异常推广反作弊

### 5.4 消费报销（P407 / P408 · V3.1 活动期任务档位）
- 报销首页：活动期横幅（起止日期 + 剩余天数）+ 状态汇总（已审核 / 结算中 / 已完成）+ 提交账单
- 今日报销档位卡：当前比例大字 + 今日原创发帖 n/4 进度条 + 档位阶梯（基础档 + 任务 1–4，当前档金色高亮）+「去发帖」直达发布器
- 档位规则（活动期内）：基础档 65% = 任意会员提交的消费帐单；任务 1–4 = 当日原创发帖累计 1 / 2 / 3 / 4 篇 → 85% / 95% / 105% / 115%
- 档位锁定：每张账单按提交当日已达成最高档锁定比例，其后发帖不影响已提交账单（提交弹窗与详情页「锁定档位」均展示）
- 结算口径：权益上限 = 审核金额 × 锁定档位；日结算 0.05% 节奏保留（线性结算达上限周期长，交互不得隐藏）
- 原创口径：当日发布成功（审核中不计）的原创帖；演示态与发布器实时联动（发布 1 篇 → 档位即时升级）
- 报销详情：原始消费 / 审核金额 / 锁定档位 / 权益上限 / 结算进度条 / 今日预计 / 结算记录 / 原始凭证
- 状态机 DRAFT → SUBMITTED → UNDER_REVIEW → APPROVED / REJECTED → SETTLING → COMPLETED / FROZEN / REVERSED
- 后台动态配置参数（报销活动引擎，原型 src/reimburse.ts 为演示值）：活动 ID、活动期起止（后台设置、App 展示）、基础比例（65%）、任务档位列表（篇数 + 比例，可增删调序）、任务口径（当日原创帖，审核通过计）、档位锁定时点（账单提交时快照）、日结算节奏（0.05%/日）
- 产品目的：把报销条件设为每日任务，拉动日活、发帖、阅读与互动
- 📋 后台活动配置界面与生效 / 下线流程、原创判定风控（防抄袭 / 最低质量 / 防刷量）、>100% 档位的风控与法务确认（防套利）、OCR 识别、六类风控（重复凭证 / 金额篡改 / 商家真实性 / 频率 / 多账户 / 时间）、8 类拒绝原因

## 7. 社交关系

### 7.1 关系模型
- 关注（单向公开订阅）与好友（双向确认、可私信）相互独立
- 好友状态机：STRANGER ⇄ REQUESTED_IN / OUT → FRIENDS → BLOCKED（可解除）
- 申请规则：验证消息、14 天有效期、频率限制、被拒短期冷却（📋 完整风控）

### 7.2 好友页（P601）
- 三 Tab：好友（搜索过滤）/ 新请求（接受 / 拒绝 + 我发出的申请撤回）/ 推荐（可能认识，共同好友 / 同城）
- 添加好友弹层：Taso ID 搜索 + 我的 Taso ID 复制 + 二维码名片入口
- 接受申请 → 自动创建会话 + 问候消息（未读 1）
- 📋 通讯录匹配（本地加密）、他人主页「加好友」按钮

### 7.3 消息中心（P602）
- 会话列表按最近排序；未读角标双级（会话级 + 全局级，首页 / 我的实时联动）
- 好友申请横幅直达新请求 Tab；空态引导加好友
- 📋 会话左滑（置顶 / 已读 / 删除）

### 7.4 聊天（P603）
- 双向气泡 + 日期分隔（今天 / 昨天 / 日期）+ 已送达 / 已读回执
- 底部输入栏：空内容禁发；未成为好友禁发并提示；本地模拟回复 + 已读
- 离开会话收新消息 → 角标 + Toast；进入会话未读清零
- 📋 消息类型扩展（图片 / 语音 / 帖子商家卡片转发，V1.5）、群聊 / 音视频（V2）、长按菜单（复制 / 撤回 / 举报）、屏蔽 / 举报完整流程、E2EE（评估中）

## 8. 广告中心（后台运营）

> 2026-09-15 增补占位：模块为后台运营能力（广告主投放 + 平台商业化运营），用户端 App 无独立入口；除 8.1 所列前台触点外整体 📋 未实现，参数口径均待定稿。

### 8.1 定位与前台触点
- 后台运营模块：服务广告主投放与平台广告运营，不直接面向 C 端用户
- 前台触点（原型已实现）：信息流原生广告帖（V1.4，见 6.1）+ 广告专属菜单（不喜欢该广告 / 为什么会看到 / 隐藏广告主 / 屏蔽广告主 / 举报广告）
- Advertiser 广告主认证标识（6 类认证之一，见 2.3）

### 8.2 广告主管理
- 📋 广告主入驻与资质审核（主体证照 / 行业资质；金融类虚假收益 / 投资诈骗为禁投重点，与 6.5 举报类别联动）
- 📋 Advertiser 认证发放与回收
- 📋 屏蔽 / 黑名单承接：前台「隐藏 / 屏蔽广告主」操作数据回流生效

### 8.3 投放管理（广告主端）
- 📋 计划 / 广告组 / 创意三级结构；排期 + 日预算 / 总预算；投放中暂停与调整
- 📋 投放目标：曝光 / 点击 / 互动 / 到店转化
- 📋 出价与计费模式：CPM / CPC / CPA（口径待定稿）
- 📋 商家自助投放与 Merchant Portal（见 3.9）打通

### 8.4 定向能力
- 📋 基础定向：内容地区（17 城）/ 界面语言 / 年龄 / 性别
- 📋 兴趣定向（承接 P004 兴趣选择冷启动标签）
- 📋 定向可解释：支撑前台「为什么会看到这条广告」话术
- 📋 再营销 / 相似人群扩展（远期）

### 8.5 创意与审核
- 📋 创意形态：信息流原生图文 / 视频广告帖（与帖子卡样式一致，见 6.1）
- 📋 素材审核：真实性 / 敏感内容 / 禁投行业；审核状态机与驳回原因
- 📋 Sponsored 显性广告标识强制展示（与 6.5 合规口径一致）

### 8.6 广告位与频控
- 📋 广告位：信息流（For You / Following 插入频率与间隔）；发现页 / 搜索结果 / 商家详情页（评估中）
- 📋 频次控制：单用户每日广告上限、同类广告去重、负反馈（不喜欢 / 屏蔽 / 举报）降权

### 8.7 计费结算与报表
- 📋 预算扣减 / 超投控制 / 广告主账单（沿用 HK$ 计价 + US$ 结算双币口径，见 3.5）
- 📋 广告主报表（曝光 / 点击 / 互动 / 转化 / 消耗）+ 平台运营报表（广告收入 / 填充率 / eCPM）
- 📋 待定稿：广告收入是否计入股东分红「平台总销售额」口径（影响 5.6 销售轨道）
